How to use

Two ways to enter data

Use the Intake, Condition report, and Add sample tabs at the top and pick the animal from a dropdown. Or expand an animal's row in the list and choose Add condition report or Add sample to open the form already filled in for that animal.

Registering a new animal

  1. Open the Intake tab and select the Tribe.
  2. Enter the Animal ID (AIN): the 15-digit USDA eartag number or another unique identifier.
  3. Set the Intake date (defaults to today). Add gender, year born, and location if known.
  4. Select the Mother if known; the list shows females already recorded for that tribe.
  5. Add comments and, optionally, attach a file. Click Save intake.

Recording a condition report

  1. Open the Condition report tab, or use the heart icon on an animal's row.
  2. Fill in body score (1–5), weight (lbs), and height (inches) if measured.
  3. Tick Injury present and describe the location if the animal is injured.
  4. Optionally record where the animal was observed. Use my location fills in your device's GPS position.
  5. Only one condition report can be recorded per animal per day. Edit the existing report instead.

Adding a sample

  1. Open the Add sample tab, or use Add sample on a condition report to use that date.
  2. Select the sample type, location, and lab. Use + Add if a value you need is not listed.
  3. The sample shows as Pending until you choose Enter result and record the lab result.

Using the animals list

  • Click a row to see condition history, samples, mother and calves, and documents.
  • Pencil edits the animal's details, including its mother. Red × records a death.
  • Attach adds a photo or document to the animal, a condition report, or a sample. Most file types are accepted except programs and scripts.
  • Show change history lists every change made to the animal and its records.
  • Export CSV downloads all of a tribe's data, if you have export access.
